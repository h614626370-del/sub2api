# v2.13.3.1

2026-10-21 自有版本发布记录。基于上游 `ranxi2001/sub2api` 正式 Release
`v2.13.3`（`472e0db09201ad3f950a512fe99812bdd3686449`），自有修订号为 1。
相对自有正式版 `v2.13.0.1`，包含上游 v2.13.1 至 v2.13.3 的更新。

## 更新内容

- 接入 OpenAI SIWC Responses 协议和独立授权流程，支持保存的 2FA，并改进授权链接展示和失败诊断。
- 增加 IP 风险控制、国家允许列表，以及可配置的请求处罚和个人安全记录。
- 支持管理员控制用户是否可见上游实际响应模型，修复 API 密钥页分组专属倍率刷新。
- 修复 Chat 转 Responses 流的过载恢复和失败统计，改进加密内容恢复、未知工具续轮处理及 OpenAI 请求期限。
- API 密钥页的一键配置、使用密钥和导入 CCS 统一采用指定默认模型：
  OpenAI 与综合分组为 `gpt-6-astra`，Grok 为 `grok-4.7`。
  同步更新 Grok Claude、Grok Build、Grok Codex 和 OpenCode 配置入口，保留模型目录的动态选择逻辑。

## 自有适配与升级

- 保留生图主控、旁路对照、订阅转换、自有更新来源和四段版本比较。
- 新增数据库迁移以本版本 `backend/migrations/` 为准，包括
  `293_security_penalties.sql`；部署前备份数据库、配置和持久化密钥。
- 请求处罚默认关闭；启用前核实策略和观察模式。SIWC 失败诊断需要匹配的托管登录 Worker。
- 模型名称是配置默认值，实际可用性仍取决于分组授权和上游账户。
- 发布安装包、重新登录运行包和 AMD64 镜像；本次不包含服务器部署。
