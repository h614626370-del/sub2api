# v2.15.0.1

2026-10-22 自有版本，集成上游正式 Release v2.15.0
（8b36fe7d647c28e8189147c6bfce52a41b6e26db），自有修订号为 1。

## 更新内容

- 修复点击立即更新后关闭窗口，再次打开无法继续重启的问题。待重启状态由前后端共同恢复，重新打开窗口或刷新后仍可继续操作。
- 支持账户一次性定时启用和停用，定时任务持久化保存。
- 增加 IP 安全审计、处罚恢复和匿名无效凭据防护；匿名防护默认关闭。
- 增加请求连接诊断，改进配额、账户调度和优先级统计。
- 改进 SIWC 共享加密会话、Responses 加密内容的账户关联，以及授权流程。
- 保留生图主控、旁路对照、订阅转换、自有更新来源、双源更新信息和四段版本比较。

## 升级说明

- 包含数据库迁移 294、295；部署前备份数据库、配置及持久化密钥。
- 沿用现有发布范围：Linux、Windows、macOS 的 AMD64 安装包，Linux AMD64 重新登录运行包，以及 AMD64 容器镜像。
- 本次操作范围为提交、推送和发布，不包含服务器部署或重启。
