# v2.10.1

基于 `ranxi2001/sub2api` 正式标签 `v2.10.1`
（`11be589504b482d77827ab383b4b53f777241238`），集成相对 v2.10.0 的 35 个提交。

## 来源更新

- 修复 OpenAI OAuth 请求回放网页搜索历史时的压缩兼容问题。
- 加入官方 Excel BPS OAuth 入口、密码/TOTP 登录工具及 BPS/Prism 协议总开关。
- 加入网站工单、New API 共享钱包查询、账号余额与额度通知、受控渠道实验。
- 更新优先调度、单号定向打票、模型选择和单输出 Token 的速度显示。

## 定制保留

- 程序内更新和重新登录运行包继续使用 `h614626370-del/sub2api`；双仓库版本检查及四段版本比较保留。
- 保留生图主控、账号独立缓存创建计费、旧定制数据库过渡迁移与历史迁移归档。
- 生图主控默认关闭；如果此前已手动开启并保存配置，升级后沿用该设置。
- 保留 SheetJS 0.20.3 的自有 SHA512 校验值、真实导出测试及发布检查。
- 路由冲突同时保留 `/admin/image-master`、`/admin/my-operations` 与 `/admin/controlled-experiments`。
- 不恢复已退役的旧 BPS 403 会话拦截和自动请求留存。

## 数据库与部署

- 本版新增 5 个迁移文件，涉及 New API 共享授权、账号通知及阈值周期、受控实验和网站工单。
- 部署前须备份数据库、配置、持久化密钥及旧程序；加密授权和 Webhook 使用的 `TOTP_ENCRYPTION_KEY` 应保持不变。
- 二进制回退不会撤销新增表、通知状态迁移或新配置；恢复迁移前状态须使用匹配的数据库与程序备份。
- 网站工单默认关闭，通知和实验需管理员显式配置或启动。
- 本次发布代码、安装包、重新登录运行包与镜像；不操作测试或正式服务器。
