# v2.10.0

基于 `ranxi2001/sub2api` 正式标签 `v2.10.0`
（`5ca3cca21eeaf4ca8a694a7f2f8f0ecd9575c549`）合并，不包含未发布的开发提交。

## 更新

- 普通 OpenAI OAuth 的 HTTP 流式 WS 加速增加发送前容量和工具兼容检查；
  默认 15 MiB 阈值，不兼容请求保留 HTTP/SSE 路径，已发送请求不会重复重放。
- 创建账号时可设置 HTTP 流式 WS 加速，默认关闭；智商测试按账号能力选择模型及推理强度。
- 修复 Chat Completions 嵌套 reasoning 配置的转发，清理已删除账号的凭据运维孤立记录。
- 集成新安装管理员凭据校验、随机凭据生成、EasyPay 回调校验和支付返回地址安全修复。
- 远程 Codex 模型目录配置支持 API Key 模型发现，前端采用 Vue 3.5.43。
- 上游采用 SheetJS 官方 0.20.3 分发包；继续保留自有下载 SHA512 校验值和真实导出测试，
  不恢复已删除的过期安全豁免。

## 保留

- 程序内更新和版本匹配的重新登录运行包继续从 `h614626370-del/sub2api` 获取。
- 保留旧定制数据库过渡迁移、历史迁移归档、回归测试和发布检查。
- 不恢复已移除的旧 BPS 403 会话拦截或四段版本兼容。

## 部署边界

- 本次仅同步、合并和发布代码，不连接或修改测试、正式服务器，也不重新部署 Prism。
- 本版相对 v2.9.11 无新增数据库迁移。WS 加速默认关闭，启用前应验收代理与客户端兼容性。
- 全新安装留空管理员凭据时会生成随机值；首次启动日志含敏感凭据，需妥善保护。
- 从旧 0.2.x 定制数据库升级前，必须备份数据库、配置及持久化密钥。
  遇到遗留独立 BPS 数据或未知依赖不得强制绕过；回退必须使用迁移前数据库，
  不能仅更换旧镜像。详见 `v2.9.4-transition.md`。
- 本地合成数据和 CI 测试不能代替真实 OAuth 模型、支付上游或生产备份恢复验收。
