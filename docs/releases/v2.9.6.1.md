# Sub2API v2.9.6.1

基于 ranxi2001/sub2api 正式版本 v2.9.6（提交 9f7d96be367e795bd76e1f45c82bd5d4c563e0fa），集成 v2.9.5、v2.9.6 的正式发布变更，新增 BPS 403 会话保护。

## 新增功能

- 实际上游路径为 `/basispoints/api/responses` 且返回 HTTP 403 时，按 API Key 与明确的 thread_id/session_id 自动屏蔽该会话。默认屏蔽 3600 秒，可配置；其他会话不受影响。
- 可独立启用自动明文留存，保存该次客户端原始正文和实际 BPS 请求正文。无需开启普通请求采集或创建任务，不保存全部 BPS 流量。
- 管理员在「系统设置 → 功能开关 → BPS 403 会话屏蔽与请求留存」配置，在「请求采集」查看「BPS 403 自动留存」记录并导出。两个开关默认关闭。
- 凭据脱敏，媒体保留摘要；正文保留本次实际提交的明文。沿用容量与保留期限，容量不足时明确标记不完整或跳过。

## 更新兼容

- 本定制发布采用四段版本号 `2.9.6.1`，程序内更新与版本匹配的重新登录运行包均指向 `h614626370-del/sub2api`，避免后续原版更新覆盖定制功能。
- 修复第四段修订号的更新比较与发布归档验证。保留 v2.9.4 过渡版的旧数据库兼容脚本，继续接入 v2.9.6 的后续迁移。
- 从旧 0.2.x 定制版本首次升级仍会执行数据库过渡迁移，升级前须备份数据库、部署配置及持久化密钥；回退旧程序需要对应的迁移前数据库。

本次为代码与 Release 发布，不包含正式或测试服务器更新、重启。程序内按钮更新实际二进制后，Docker 镜像标签不随之改变。
