Sub2API v0.2.7.8

## 本版更新

### Astra、Sol 按来源分组路由

- Astra、Sol 分别配置「适用分组」和「目标分组」，互不影响。仅选中的来源分组在模型匹配且设置目标时使用目标账号池；未选中、空名单或「使用原分组」均保持原调度。
- 适用分组支持搜索、多选、已选数量、全选当前可用分组和清空。可选择启用的 OpenAI、合成分组，不包含特殊分组；合成分组仅在实际请求走 OpenAI 时应用规则。
- 目标仍限启用的 OpenAI 特殊分组。已选但停用、删除或不再符合条件的分组保留异常提示，允许移除，不静默清除配置。
- 路由依据 API Key 原本绑定的分组，只改变账号池，权限、计费、订阅和利润控制仍归原分组。未命中的来源不受失效目标影响；命中后目标不可用则报错，不回退。
- HTTP、流式、Token Count、普通及高级调度器共用规则，并保留粘性会话、previous-response 和重试的账号池隔离。WebSocket 后续轮次重新检查规则及账号分组，不再符合账号池要求时提示重连。
- 新增设置字段 `openai_astra_source_group_ids`、`openai_sol_source_group_ids`。省略保留原值，空数组清空；保存前校验、去重排序，来源名单和目标配对读取、缓存并在保存后失效。

### 统一请求时区与代理覆盖

- 在「定制功能 → 账号请求时区」直接设置统一时区，无需先选账号。支持搜索中文城市和标准时区名称，独立保存并热更新。
- 优先级固定为「有效代理识别时区 → 统一时区 → 客户端原值」。统一值默认为空，可选择「保留客户端时区」清除统一值。
- 账号时区详情默认折叠，仅可选择 OpenAI OAuth 账号，显示实际时区、来源、代理出口 IP 和检测时间；只保留重新检测代理操作，无代理时禁用检测。
- 沿用按需代理检测；保存统一时区不会批量探测，设置统一值也不会阻止缺失结果的账号检测代理。检测失败或冷却期间回退统一值，同一代理已有的有效结果继续保留。
- 代理更换和长连接场景校验代理指纹，避免使用其他代理的识别结果。仅处理既有环境日期、时区和 Web Search 时区，不修改普通消息、报表或计费时区，与打票开关独立。

### 打票设置归拢

- 将打票相关开关、代理及策略设置集中到「打票详情」页签的折叠设置区，独立保存。
- 「定制功能」保留路由和请求时区配置，减少跨页查找与误覆盖。

## 升级注意

- 本版沿用官方 `0.2.7` 基线，仅递增定制版本第四段。
- 新增一次性迁移 `242_openai_model_route_sources.sql`，只补充设置，不新增表，由程序启动时的现有迁移机制执行。
- 旧版已配置目标、但尚无来源名单的路由，会保存升级时全部可用来源分组 ID，以保持已有路由范围。未启用路由或新安装保存空名单；已存在的名单（包括空数组）不会被覆盖。
- 升级后新建分组默认不强制路由；取消勾选即可恢复该来源的原调度。迁移幂等，失败会阻止完成升级，不静默切换语义。
- 旧账号手动时区数据保留用于回退，但不再参与生效计算，也不会自动转成统一时区。旧账号手动设置接口明确拒绝写入；原先依赖手动时区的用户应在升级后配置统一时区或使用代理识别。
- 建议升级前备份数据库及部署配置。发布本身不会自动部署或重启现有服务器。
