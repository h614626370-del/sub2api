# v2.17.5.1

2026-10-27，从自有 v2.15.0.1（`3faa93163`）合入上游正式 Release v2.17.5，
对应提交为 `e2316d931015a9ec67955401147fb9ab3bfa52b2`。
不包含该标签之后的 production 分支提交。
上游标签内 VERSION 仍为 2.17.4，本地按正式 Release 标签设置自有版本为 `2.17.5.1`。
本次执行提交、推送和正式发布；发布结果以对应 GitHub 工作流为准。

## 主要更新

- 持久化计费事件、账务恢复、计费报价和平台额度增量处理，提高扣费与用量记录的一致性。
- 新增用户流量记录与查询，保留已有用量页面和请求诊断。
- 增强内容风控恢复、豁免管理和证据留存。
- 增强批量生图的资金处理、质量规则预设及账号重新登录预算。
- 合入上游账号管理、协议适配、前端依赖安全更新及相应测试。
- 修复上游新增模型校验与自有直连生图模式的兼容问题，保留不支持直连时切换账户的错误语义。

## 保留的定制

- 管理员订阅转余额：确认后原子撤销订阅并增加余额，不再检查在途请求或未结算记录。
  转换集中在独立后台服务文件，与主程序一起部署；请求与计费流程移除转换租约，
  旧租约不阻止转换，Key 分组由用户自行切换。
- 生图主控、旁路对照、相关敏感读取审计，与新增流量中间件共同保留。
- 单账号“创建缓存按普通输入计费（无需 BPS）”及原有 BPS 计费开关。
- 自有更新和重新登录运行包来源、双仓库版本展示、四段版本比较及待重启状态恢复。
- AMD64 发布范围、旧数据库过渡迁移、SheetJS 官方包校验和真实导出测试。
- 支付看板日期范围及既有自有功能。

## 升级范围

- 新增上游数据库迁移 296–308，涉及风控、证据、质量规则、重新登录预算、
  计费事件与报价、批量生图资金、平台额度和流量记录。
- 部署前应备份数据库、配置和持久化密钥；代码回退不能替代数据库恢复。
- 本次不连接服务器，不执行服务器迁移、部署或重启。
- 发布 Linux、Windows、macOS AMD64 安装包、Linux AMD64 重新登录运行包及 AMD64 容器镜像。
