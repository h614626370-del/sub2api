# Sub2API v0.2.8.6

## 更新内容

- 支付概览支持指定历史月份、连续月份和自定义日期范围；新增本月、上月、近六个月、今年、去年等快捷筛选，单次统计最长 366 天。
- 收入趋势支持按日或按月查看；按服务端时区统计，历史区间与今日指标分别计算，修复日期边界及并发请求覆盖问题。
- 完整移除内置 BPS 的路由、协议转换、缓存实现、账号模式、诊断状态、管理界面和专属测试，恢复常规 OpenAI 处理流程。后续 BPS 接入通过插件完成，本版本不自动安装第三方插件。
- 插件兼容检查支持四段定制版本号：例如 0.2.8.6 使用 0.2.8 判断版本范围，第四段仍用于定制版本展示和更新比较；未明确测试定制版本的插件仍提示“兼容但未测试”。

## 升级说明

- 首次启动执行 248_remove_builtin_bps.sql，永久删除旧 BPS 账号、分组及相关数据，清除普通账号中的 BPS 配置字段，并恢复平台约束。内置 BPS 没有独立业务表，不删除普通账号、用户或共享业务表。
- 清理不备份 BPS 数据；普通 OpenAI 凭据、打票、账号时区及其他定制功能保留。
- 依赖内置 BPS 的客户端应在部署切换前准备好插件接入。已有 BPS 对话状态不能由本版本继续使用。
- 发布不等于部署：本次发布不会重启现有服务器。旧进程停止后可单独清理 Redis 的 openai_bps:* 命名空间；这些键原有有效期为 7 天，新版不再读写，禁止清空整个 Redis 数据库。
