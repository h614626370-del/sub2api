# v2.11.0.1 合入与发布记录

2026-10-15 将 `ranxi2001/sub2api` 正式 Release `v2.11.0` 合入自有 `main`。
上游提交为 `a78ae7f3bed6cdd30d740b2defee12aaf097c8f5`，
合入前自有提交为 `47d0a4860`（`v2.10.7.1`）。未包含该正式标签之后的开发提交。

发布产物由 `v2.11.0.1` 标签触发的 Release 工作流生成，实际结果以 GitHub 工作流和 Release 为准。
本次未连接或部署服务器。

## 上游更新

- 集成 Gemini 显式缓存、Vertex 兼容改进、分组多语言显示和分组缓存测试。
- 集成在途余额预留、Responses/Chat 回退修复、缓存率显示设置和调度读取优化。
- 集成区域鉴权、调度同步、共享槽位和资金账本基础设施。区域模式仍默认关闭，
  遵循上游预览限制；本次不补齐真实区域模型转发，不移除未支持路径的 503 保护。

## 定制保留

- 图片主控、Responses 转图片直连、旁路对照和独立测试 Key 选择。
  延续提取支持字段、忽略未知字段的兼容处理。
- 仅管理员可操作的订阅转余额、原子到账和审计，以及请求和异步扣费期间的持久化保护。
- 支付概览扩展日期范围、账号级 OpenAI 缓存创建按普通输入计费。
- 双仓库版本展示、三段及四段版本比较；更新和重新登录运行包仍取自自有仓库。
- 旧定制数据库过渡 SQL、历史迁移归档，以及仅 AMD64 的发布配置。
- 已移除的 BPS 403 会话屏蔽和自动请求留存保持移除。

## 合并适配

- 网关异步计费同时持有上游余额预留引用和自有订阅转换保护引用。
  任务成功或异常时释放引用；任务放弃时释放预留并标记订阅结算不明。
  清理幂等，订阅计费在队列溢出时继续同步执行，避免漏扣。
- 新增同时持有两种计费保护的成功、放弃、异常回归测试。
- 旧数据库升级快照适配分组新增 `i18n` 列，并单独断言历史分组默认为空多语言配置；
  不修改历史迁移或过渡 SQL。
