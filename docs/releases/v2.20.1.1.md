## 定制兼容

- 保留管理员订阅转余额、独立服务、鉴权缓存失效和原子到账逻辑。
  不恢复已移除的在途请求或待结算阻断。
- 保留生图主控、独立测试 Key 旁路对照及禁止主控回退的直连策略。
  新增 Key 模型策略和长上下文准入在原始 Responses 请求进入生图转换前执行；
  转换后的图片模型仍经过分组白名单及路由检查。
- 保留单账号缓存创建按普通输入计费和扩展支付统计日期范围。
- 保留自有更新与重新登录运行包来源、双仓库版本展示、四段版本比较、
  AMD64 发布范围和自有默认模型。
- 同时注册自有页面与上游 AI 运维、抽奖及新增语言词条；保留生图敏感读取审计。
- 旧迁移过渡 SQL 与历史归档未修改。升级快照单独排除本次新增字段，并断言
  历史 Key 的默认模型策略、长上下文权限及历史用量的未知计时状态。
- 为完整网关路由补充生图主控开启时仍拒绝不可核实长上下文的回归。
- 补齐上游 OpenAI 响应头超时设置的搜索入口，并让锚点检查覆盖侧栏设置子组件。
  更新字段相邻关系、账号外链、模型目录替换及新功能提示的前端测试夹具，
  保留原有业务校验。
- 修复 BEpusdt 的 SQLite 时间格式兼容问题，连接显式使用 SQLite 时间格式，
  确保收款确认时间可以正常读回 `time.Time`。
