# Sub2API v0.2.10.1

## 更新内容

- 合并官方正式版本 v0.2.10，定制版本号为 0.2.10.1。
- 保留支付概览的历史月份、连续月份、自定义日期范围及按日或按月收入趋势。
- 保留私有仓库更新、打票、账号时区等定制功能，接入官方 Claude 重置额度及网关更新。
- 插件兼容检查按官方基线 0.2.10 判断版本范围；第四段保留为定制版本身份，未明确测试定制版本的插件仍提示兼容但未测试。
- 打票按实际转发模型及 compact 映射判断，同时保留官方模型级临时冷却的查询规则。
- 内置 BPS 已完整移除，后续通过插件接入；本版本不自动安装第三方插件。

## 升级说明

- 从尚未执行清理的旧版本升级，首次启动执行 248_remove_builtin_bps.sql，永久清除旧 BPS 账号、分组及配置，不备份 BPS 数据。
- 内置 BPS 没有独立业务表，不删除普通账号、用户或共享业务表；普通凭据、打票和账号时区保留。
- 本次仅发布，不切换或重启测试环境、正式环境。

## 发布产物

- Linux amd64/arm64、macOS amd64/arm64、Windows amd64 安装包及 SHA-256 校验文件。
- 私有镜像 ghcr.io/h614626370-del/sub2api:0.2.10.1，支持 linux/amd64 和 linux/arm64。
