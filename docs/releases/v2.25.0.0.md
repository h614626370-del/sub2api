# v2.25.0.0 合入记录

2026-11-25 将 `ranxi2001/sub2api` 正式标签 `v2.25.0`
（`0fa2cb6ac91effee2a45b933bb44b460f05a8c49`）合入自有 `main`。
自有父提交为 `6fa93b951`，合并基点为上次合入的 `v2.24.3`
（`691a36fc39aea4419bc2b114ef76303647dfccd1`）。自有版本使用 `2.25.0.0`。

## 合并范围

- 引入来源版本的账号上游分组同步、请求头身份变量、国模线路自动调度、
  分组健康 API、利润采购基数核算、千问思考强度适配及网关错误透传修复。
- 同步来源版本移除用户流量记录的改动。升级启动时，
  `398_drop_user_traffic.sql` 会删除 `user_traffic_events` 和 `user_traffic_hourly`，
  对应历史流量数据无法通过程序回退恢复；正式升级前应备份数据库。
  该迁移不删除 `usage_logs` 用量账单。
- 保留教程中心、ZIP 导入导出、自定义教程路径、独立首页及资源管理、
  订阅转余额、生图主控与旁路、自有更新与重新登录包来源、四段版本兼容、
  Linux AMD64 发布配置及旧库迁移归档。
- 处理版本文件、网关路由和路由覆盖测试三处冲突。
  网关链移除来源已删除的流量记录中间件，保留自有生图主控及旁路的执行顺序。
- 六个新增迁移按原完整文件名保留；迁移系统以完整文件名跟踪并排序，
  可与既有 `394_homepage_assets.sql`、`395_tutorial_routes_and_asset_cleanup.sql` 共存。
  合并前已有的 521 个迁移和归档文件均未改写。
- 旧库升级测试将新增的线路探测时间列独立验证为空，业务快照继续核对原字段；
  代理探测失效测试只统计当前账号的 outbox 事件，避免其他测试数据干扰。

最终检查结果见该目录的 `VERIFICATION.md`。

  两项失败用例均已独立复跑通过，合计覆盖 6,692 项通过用例。
- 前端 ESLint 无错误，保留 1 个既有 warning；中英文键完整性、TypeScript 及生产构建通过。
- PostgreSQL/Redis 定向集成 58 个主测试、199 个含子场景结果全部通过，
  覆盖来源新增迁移、利润汇总、账号状态与分组同步、旧库升级及订阅转换。
- handler/service 定向单元测试 180 个主测试通过、1 个因 Unix 原地更新语义跳过；
  含子场景共 641 项通过，覆盖本次改动与交叠的自有逻辑。
- `CGO_ENABLED=0`、`-tags=embed` 的 Windows AMD64 主程序构建通过，
  已包含本轮前端产物，执行 `-version` 输出 `2.25.0.0`。

  详情见本地 `backend-other-summary.json`，未将这些结果记为通过。

  导致临时目录清理失败；未修改原有安全权限逻辑或弱化断言来规避平台差异。
