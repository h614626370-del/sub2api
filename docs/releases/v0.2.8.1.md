# v0.2.8.1

本版基于官方 v0.2.8，包含 BPS 账号模式调整和新安装时区默认值更新。

## 更新内容

- BPS 不再作为独立平台和分组使用。普通 OpenAI OAuth 账号新增“启用 BPS”开关和可编辑模型列表，默认关闭；开启时默认模型为 `gpt-6-astra`、`gpt-5.6-sol`。
- 继续使用原 OpenAI 分组、API Key、账号优先级、并发限制和 OAuth 凭据。先选择账号，再按映射后的上游模型精确判断通道；请求重试不自动跨通道回退。
- BPS 复用 OAuth Token Provider 和刷新锁，认证失败最多刷新并重试一次；不具备刷新条件时提示重新授权。BPS 特有错误和模型限流不单独停用整个普通 OpenAI 账号。
- BPS 会话保持账号绑定及 API Key 隔离；不兼容的会话配置需要新建会话。仅支持 HTTP Responses 和 compact，不支持的接口或 WebSocket 返回明确错误。
- 账号编辑无需重复填写 Token，账号列表展示 BPS 标记，连接测试按所选模型使用对应通道。
- BPS 使用固定上游地址及账号代理，不使用普通 OAuth 自定义 Base URL。普通 OAuth 自定义地址、打票与既有模型路由保留。
- 新安装的系统时区、部署模板和账号请求统一时区默认使用 `America/Los_Angeles`。已有明确配置（包括主动留空的账号请求时区）保持不变。

## 升级前必读

**本版包含不可通过程序降级恢复的数据库清理。部署前必须另行确认并完成数据库备份。**

- 迁移 `247_retire_standalone_bps.sql` 将停用并软删除旧 `openai_bps` 账号和分组，清除旧账号凭据，不自动转换或合并为普通 OpenAI 账号。
- 关联 API Key 停用并解除旧分组绑定；相关订阅权益、商品、未使用兑换码、聚合路由和监控配置停止使用，活动关联清理。
- 历史用量及审计记录保留，普通 OpenAI 账号、分组和凭据不属于清理目标。
- 鉴权、订阅和 BPS 会话缓存更新；旧 BPS 会话不可继续使用。请在普通 OpenAI OAuth 账号开启 BPS，并使用原 OpenAI 分组的有效 API Key 新建会话。
- 仅回退镜像或二进制不能恢复已清除的凭据、旧权限或会话。此前任何“不备份删除测试库”的授权均不适用于此次升级。

## 验收范围

自动化验证不代替真实账号的上游验收。BPS 权限、真实 OAuth 授权及出票结果仍取决于对应账号与上游服务。本次发布不自动部署或重启现有服务。
