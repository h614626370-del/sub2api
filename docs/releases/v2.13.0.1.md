## 更新内容

- API Key 支持最多绑定 20 个有权使用的分组，按模型、权限、额度、容量及有效倍率选择可用分组；已有单分组 Key 保持兼容。
- 账号管理支持展示上游多分组倍率声明；多分组声明不再被误写为单一账号成本倍率。
- 模型广场补充账号池可用模型，同时保留平台隔离与分组模型限制。
- 修复自定义页面向外部 URL 传递主登录 JWT 的问题，清理历史 token 参数并限制来源信息。
- ChatGPT 会话导出改为异步 Worker 任务流程，替换旧 Cookie 直导方式。
- 增加分组 Codex CLI 专用与子代理限制、MiniMax H3 支持，以及渠道监控时间线和分组排序改进。

## 自有适配

- 保留“我的运维 > 生图主控”及旁路对照入口，并与上游新增的分组限制中间件共同接入网关。
- 保留订阅转换的视频未结算保护与延迟计费，同时接入上游 MiniMax H3 成本记录。
- 保留支付履约 `Converted` 状态兼容，以及自有更新来源、四段版本比较和发布配置。
- 生图主控及旁路开关的实际启用状态由部署实例配置决定。

## 升级注意

- 外部自定义页面若依赖 URL 中的主登录 JWT，升级前须改为独立认证。`user_id` 不能作为授权凭据。
- 使用区域本地鉴权快照的网关继续使用单分组 Key；启用多分组前应核实网关模式与上游倍率声明 schema v2 兼容性。
- 多分组 Key 降级后，旧版只识别主分组，不会按额外绑定分组路由。
- 会话导出操作应按新的 Worker 任务流程验收。
- 部署前备份数据库、配置、持久化密钥及生图主控数据；代码版本不代表服务器已升级。
