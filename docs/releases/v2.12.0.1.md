# v2.12.0.1

2026-10-17 将上游 `ranxi2001/sub2api` 正式 Release `v2.12.0` 合入自有 `main`，
并以自有第四段修订号 1 发布。上游正式标签提交为 `7393d736e`，
合入前自有提交为 `5611932b3`（`v2.11.0.1`）。
本次不包含上游正式标签之后的未发布提交。

## 更新内容

- 新增 ChatGPT 会话导出，复用加密登录信息并提供管理员操作界面。
- 增强账号质量运维：按模型隔离处置、随机推理题、瞬时错误重试和失败换号。
- 增加注册及登录撞库防护，包括单 IP 注册限制、凭证错误计数和 IPv6 网段防护。
- 改进 OpenAI Responses、`web_search` 模拟、模型别名和 GPT-5.5 退役策略。
- 增加 Gemini 4 Argon、思考档位及流式思考摘要支持，改进 Antigravity 模型目录和工具结果兼容。
- 修复 EasyPay、支付宝、Stripe 支付查询、上游确认、退款挂起和订单类型校验。
- 改进 Anthropic Base URL、最小输出 token、Composite 路由和请求时区处理。
- 改进渠道监控、托管 Worker 迁移和相关运维行为。

## 自有适配

- 保留自有支付履约的 `Converted` 状态兼容。
- 保留自有仓库的版本、更新来源和发布配置。
- 上游已清理旧的图片 Master/Shadow 和订阅转换模块，随本次正式版本同步。
