# 首页管理

进入「我的运维 → 首页管理」。每个实例只维护一份首页，不提供模板或单独的发布步骤。

- 未保存过 HTML 时，编辑框会预填一份沿用原版样式的静态首页。可直接修改或替换，不会覆盖已有 HTML，也不会自动发布。
- 勾选「启用独立首页」，填写公开主域名（例如 `https://example.com`）和不超过 1 MiB 的 UTF-8 `index.html`，保存后生效。
- 启用后，`/` 直接返回保存的 HTML，`/home` 和 `/home/` 以 `301` 跳转到 `/` 并保留查询参数。
- SEO 标题、描述、`canonical`、Open Graph 和 JSON-LD 直接写在 HTML 内，不重复配置。编辑页提示常见 SEO 问题，不改写源文件。
- `/robots.txt` 由后端生成；启用时声明 `/sitemap.xml`，后者仅收录配置主域名的首页。教程未加入本站点地图。
- 保存会保留上一版完整配置（开关、主域名、HTML）。恢复立即生效，并把刚换下的版本保留为上一版。并发编辑发生冲突时不会覆盖新版本。
- 关闭独立首页并保存后，继续使用原有首页（含系统设置中的旧 `home_content`）；关闭开关不会清空编辑框。仅后台模式不对外提供首页。

首页允许 HTML/CSS、普通链接以及符合页面策略的图片和字体。禁用 JavaScript、表单提交和嵌入，禁止 `meta refresh`。不要在首页 HTML 放置密钥。首页配置和上一版随 PostgreSQL 备份保存。

## 从 Guide 切换

1. 迁移 HTML 和它引用的静态资源，核对链接与规范地址。仍依赖 Guide 的 CSS、图片、字体及动态功能不会自动迁移。
2. 先在 Sub2API 启用并验收，再将反代的 `/`、`/robots.txt`、`/sitemap.xml` 交给 Sub2API。若已有 `/home` 跳转可保留，确保没有循环和缓存旧首页；旧 `/site-home/` 资源不要在替换前移除。
3. 等剩余 Guide 页面和直接链接完成迁移后，再下线 Guide。此功能不操作原 Guide 服务。
