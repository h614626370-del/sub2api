## OpenAI 缓存创建计费（2026-10-08，未发布）

- 单个 OpenAI 账号的编辑弹窗中，在名称下方新增“创建缓存按普通输入计费（无需 BPS）”
  开关，默认关闭。使用账号自己的 `extra.openai_cache_creation_as_input`，
  不要求启用 BPS，适用于 OAuth、API Key 和 Setup Token；影子账号可独立配置。
- 开启后，统一 OpenAI 用量结算将上游报告的缓存创建 token 并入普通输入，
  本站用量日志中的缓存创建 token/费用归零，缓存读取和输出保持原计费规则。
  余额、订阅扣费及基于该用量的账号费用统计使用同一口径。
- 不修改上游缓存行为或原始响应，不推算上游未报告的缓存创建用量。
  原有 BPS 专用开关及其下游用量改写保持不变；两个开关任一个满足原适用条件，
  都会将缓存创建按输入结算。关闭新开关不会关闭原有 BPS 专用设置。
- 使用现有 JSON 扩展字段，无新增数据库迁移。此功能尚未发布或部署。
- 本地验证：前端账号编辑、自动 BPS 及语言键完整性共 151 项测试、类型检查、
  生产构建通过；后端独立开关、账号更新、缓存计费、原有 BPS 及
  `OpenAIGatewayServiceRecordUsage` 定向回归通过。
  本地浏览器使用模拟账号验证桌面/手机布局及开启后的保存回显；未调用真实上游。

## 移除

- 删除 BPS 403 会话拦截逻辑、自动正文留存、设置字段、后台开关与专属说明。
  原有 `bps403_*` 设置不再读取或更新；旧屏蔽记录不再参与请求判断。
- 不主动删除历史请求采集文件、数据库记录或 Redis 键。普通请求采集沿用
  原有开关、权限、容量与保留期限；查看历史采集记录需开启普通请求采集。
- 四段版本兼容曾于 2026-10-01 移除，2026-10-08 按用户要求恢复，见下节。
  旧标签和历史发布说明保留，不回写历史。

## 生图主控（2026-10-08，未发布）

- 参考自有 `responses-image-bridge`，新增“我的运维 > 生图主控”，位置在
  “智能运维”之后、“插件”之前；开关位于主控设置顶部，默认关闭。
- 使用 Go 站内网关调用，复用本站鉴权、账号调度和计费；无需上游地址、
  管理员 Key、独立登录或额外 Node 服务。未移植账号诊断相关功能。
- 含唯一图片工具的 HTTP Responses 请求转换为同步图片接口：文生图调用
  `/v1/images/generations`，图生图调用 `/v1/images/edits`。图片模型必须显式指定在
  工具内，删除主控模型及单独图生图直连设置；不安全转换的输入明确报错。
- 接管的请求禁止回退主控，账号模型不支持或直连 404/405 时使用原网关有界账号切换；
  跨节点通过签名票据保留策略，不支持策略的旧节点拒绝请求。
- 保留 Responses JSON/SSE、心跳、单条取消、请求监控及受保护的可选原始日志。
  普通对话、直接图片请求、WebSocket 及关闭功能后的原流程不变，不新增数据库迁移。
- 不设置主控独立并发、排队或暂停/恢复，统一沿用本站分组及网关策略；
  只保留主控启用开关，关闭时恢复原网关处理，不禁止生图。
- 配置和日志按当前实例落盘，不是集群全局状态。支持公网 HTTPS 原图，
  远程图片使用 Go 无损规范化为 PNG，不依赖 sharp。
- 使用方式、安全限制和待验收范围见 `docs/image-master.md`。
  本次仅本地集成，未发布、未部署、未发起真实收费生图。
