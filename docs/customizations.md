# 当前保留的定制

以 `ranxi2001/sub2api` 正式版本 v2.9.10 为当前代码基线。2026-10-01 按用户要求移除
BPS 403 会话屏蔽、BPS 403 自动请求留存，以及四段版本号兼容。
删减已先单独提交，随后集成 v2.9.7。2026-10-06 在本地继续合并正式标签
v2.9.10（`ab7cb27ceed6390441277784cc5560694d95fd73`），不包含标签之后的开发提交。
本次未推送、未发布新 Release，也未更新或重启任何服务器。

## 保留

- 程序内更新和版本匹配的重新登录运行包仍从
  `h614626370-del/sub2api` 的 Release 获取。
- 保留 `260z_h614626370_transition.sql`、旧迁移归档与相关测试，
  继续支持旧 0.2.x 定制数据库的过渡。原有备份及回退要求不变。

## 移除

- 删除 BPS 403 会话拦截逻辑、自动正文留存、设置字段、后台开关与专属说明。
  原有 `bps403_*` 设置不再读取或更新；旧屏蔽记录不再参与请求判断。
- 不主动删除历史请求采集文件、数据库记录或 Redis 键。普通请求采集沿用
  原有开关、权限、容量与保留期限；查看历史采集记录需开启普通请求采集。
- 版本比较恢复来源版本的三段比较逻辑，第四段不再作为升级排序依据。
  发布构建与重新登录运行包仅接受三段版本号及来源版本支持的预发布后缀，
  不再接受四段版本号。旧标签和历史发布说明保留，不回写历史。

## 未改动

来源版本自带的 Excel/BPS 转发、账号级 BPS 403 处理、普通请求采集、
cyber 会话风控以及其他功能均未移除。本次不等于删除整个 BPS 模块。

当前 `VERSION` 为 `2.9.10`。此前的自有 Release 不包含本次本地合并变更。
后续发布版本号以用户明确指定为准。
